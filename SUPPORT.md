# OmniCOVAS community support

OmniCOVAS is currently a **build-from-source Windows project**, not a released
installer. Please check the [README](README.md) before attempting a build.

| Need | Where to go |
| --- | --- |
| Ask a question, discuss a workflow, share a tip | [GitHub Discussions](https://github.com/RocketsProjects/OmniCovas/discussions) |
| Chat with fellow Commanders and follow development | [OmniCOVAS Discord](https://discord.gg/EPXXb2AMJX) |
| Report a reproducible app defect | [Bug report](https://github.com/RocketsProjects/OmniCovas/issues/new/choose) |
| Report compatibility with VR, overlays, Windows, or other companions | [Compatibility report](https://github.com/RocketsProjects/OmniCovas/issues/new/choose) |
| Request a concrete feature or usability improvement | [Feature request](https://github.com/RocketsProjects/OmniCovas/issues/new/choose) |
| Report a security vulnerability | [Private reporting guidance](SECURITY.md) |
| Ask permission to contribute code or discuss licensing | [Contributing](CONTRIBUTING.md) |

Before posting, search existing issues and discussions. State the OmniCOVAS
commit/version and exact third-party tool versions where relevant. Only attach
short, **redacted** diagnostics; public GitHub posts should not contain access
tokens, full Journal files, commander/account identifiers, or unredacted logs.

The project is maintained on a volunteer basis. Feedback is welcome, but a
response time or requested feature cannot be guaranteed. Code contributions
require separate agreement under the [contribution terms](CONTRIBUTING.md).
